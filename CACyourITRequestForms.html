Consult Request (New/Revised order builds only). A separate SNOW ticket should be entered for each consult request.

This form is for DVAHCS request. Please use this form to request the creation, modification, or termination/deactivation of a menu, order, or order set. Complete all information and attach additional information, as required. Submit form via "VistA/CPRS Request – YourIT/SNOW" as an attachment. All new menu, order, or order set requests must include an attached Word document with a mock-up of the item. Requests submitted without this attachment will be closed.

Please use this form to request the creation of new templates, change an existing template(s), boilerplates, titles, or terminate/deactivate a progress note. If this request is for data collection STOP, and submit a YourIT/SNOW ticket. Complete all information and attach additional information, as required. Submit form via "VistA/CPRS Request – YourIT/SNOW" as an attachment. All new template(s) requests must have an attached Word document with a mock up of the template. Failure to do so will result in your ticket being CLOSED.

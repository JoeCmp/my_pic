CPRS Note & Image Retraction Instruction

General Guidance
⚠️ Important: CACs can retract regular notes directly, but cannot retract notes with an associated image. Those require a LEAF image deletion request.

📝 Regular note (no image icon)

1
Write an addendum to the note.
2
State clearly in the addendum why the note needs to be made hidden.
Example: "The note was written on the wrong veteran."
3
Tag the CAC team in the addendum so the note can be retracted for you.

👤 Author matching rule

  • ✓ The author of the note or addendum must match the person requesting retraction
  • ✓ Only submit a retraction request for someone else's note if you are their supervisor
  • ✓ If acting as a supervisor, this relationship must be identified in the request

🖼️ Note with an image — LEAF image deletion request

Complete the same addendum steps above, plus submit an image deletion request through the Durham LEAF Portal:
1
Go to the Durham LEAF Portals.
2
Select "New Request."
3
In Step 1, title the request: "Image Deletion" + Veteran's Name + last 4 digits of SSN.
4
In Step 2, choose "HAS/HIMS Image Deletion" (everything is listed alphabetically).
5
In CPRS, go to Tools > Imaging (VistA Imaging Display), Select the correct Image and locate "Image ID#"
6
On the "Image Deletion Request Information" page, provide:
Veteran Name Social Security Number Image ID# Reason for Deletion Attachment (optional, max 20MB)
7
Follow the prompts to submit. Confirm you receive a confirmation message or receipt.
8
After the image is removed, notify CAC team so we can keep the note status updated.

🚫 Don'ts

✗ Retract an image-note yourself
✗ Submit for someone else's note without supervisor status
✗ Skip identifying the supervisor relationship
✗ Submit duplicate LEAF requests for the same image
